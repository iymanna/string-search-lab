# String Search Lab

同一段文本，用朴素匹配和 KMP 各找一遍，顺便数一下比较了多少次。

```sh
python3 search.py demo
python3 search.py find 'KMP' README.md
```

Python 3.9 以上就能跑。第二条命令可以换成自己的关键词和 UTF-8 文本文件。

| 例子 | 匹配位置 | 朴素匹配 | KMP（含前缀表） |
| --- | --- | ---: | ---: |
| 在 `aaaaa` 里找 `aaa` | 0、1、2 | 9 | 7 |
| 在 10,000 个 `a` 加一个 `b` 里找 99 个 `a` 加一个 `b` | 9901 | 990,200 | 20,099 |

第二个例子里，朴素匹配总要比到最后一个字符才发现是错的。KMP 用前缀表记住已经对上的那段，失配之后可以接着比。

下标从 0 开始，按 Python 字符串的位置算。重叠的匹配也会计入，终端最多列出前 12 个位置。表里统计的是字符比较次数。

```sh
python3 -m unittest -v
```
